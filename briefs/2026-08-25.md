### 1. Agent 上线不是一次性验收：240 项测试实践暴露“测试到实战”的推理断层
- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv / 2026-08-24（新提交列表上线；v1 于 2026-08-20 UTC 上传）
- 摘要：一项面向军事指挥控制场景的结构化综述梳理了 240 项测试与评估实践，归纳出传统方法对系统可规格化、稳定性、可组合性和可监督性的 8 个关键假设；论文认为，Agent 特性会削弱全部 8 个假设。作者没有据此宣称 Agent 无法评估，而是把可辩护的结论收窄到任务边界、轨迹正确性、可执行运行时约束和多次运行方差等具体主张，并强调部署后的持续取证。
- 为何重要：这把高风险 Agent 的核心问题从“有没有跑过测试”推进到“测试证据能否支撑上线后的行为主张”。对企业同样有启发：验收应附有效期、责任人和运行期证据，不能把一次离线通过当作长期安全保证。
- 原文：[Testing and Evaluation of Agentic AI Systems In Military Command and Control](https://arxiv.org/abs/2608.20597)

### 2. Meta 公开大规模发布健康检查：异常自动回滚只是起点
- 领域：软件工程
- 来源 / 发布日期：arXiv（IEEE ISSRE 2026 Industry Track 论文）/ 2026-08-24（新提交列表上线；v1 于 2026-08-20 UTC 上传）
- 摘要：Meta 介绍了覆盖数千个异构服务的 Service Health Checker：发布检查由模板化指标查询、阈值和工作流条件组成，并接入分层、分阶段发布，在回归出现时自动暂停或回滚。论文的重点不只是架构，还包括规模化后出现的噪声、告警疲劳、规则漂移和未覆盖回归，以及用度量、历史回测、工具和更佳默认值持续治理这些问题。
- 为何重要：可靠发布并不是增加一道静态门禁，而是维护一个会漂移的控制系统。历史回测、覆盖率和默认策略决定了自动回滚究竟是在降低事故，还是制造新的噪声与盲区。
- 原文：[Making Deployments Safe at Meta: Health Checks for Continuous Change-Safety](https://arxiv.org/abs/2608.20513)

### 4. Waymo 自研 5nm ASIC：Robotaxi 竞争进入软硬件协同与单位经济阶段
- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：TechCrunch Mobility / 2026-08-23（Waymo 技术披露发布于 2026-08-20）
- 摘要：TechCrunch 结合 Waymo 的技术披露分析了第六代 Ojai Robotaxi 的计算系统：Waymo 自研 5nm ASIC，在传感器数据进入核心“驾驶大脑”前执行实时处理与融合，单芯片提供超过 1,000 TOPS 的机器学习性能，并同时处理 13 路高分辨率摄像头数据。Waymo 仍与 AMD、NVIDIA、Micron、Samsung、Sandisk、Socionext 和 TSMC 等伙伴协作，采用的是关键环节定制、其余部分组合供应链的路线。
- 为何重要：Robotaxi 从示范运营走向扩张后，瓶颈不只在模型能力，还在毫秒级延迟、车载能效、可靠冗余和单车成本。Waymo 的纵向整合说明，自动驾驶规模化正越来越像一场芯片、传感器、模型与整车共同优化的系统工程。
- 原文：[TechCrunch Mobility: The custom chip driving Waymo’s robotaxi ambitions](https://techcrunch.com/2026/08/23/techcrunch-mobility-the-custom-chip-driving-waymos-robotaxi-ambitions/)

### 5. BC-Bench 把 Coding Agent 拉进 ERP：通用榜单提升未必迁移到企业 DSL
- 领域：AI / 智能体（AI 编程）
- 来源 / 发布日期：arXiv / 2026-08-24（新提交列表上线；v1 于 2026-08-21 UTC 上传）
- 摘要：BC-Bench 收录 101 个从两个 Microsoft 生产仓库人工筛选的真实任务，评估 Agent 在 Dynamics 365 Business Central 的 AL 领域语言上修复缺陷和生成测试，并支持含截图的问题描述。论文用 GitHub Copilot 与 Claude Code 两种生产级 harness、多次独立运行进行比较；在其 Bug Fixing 设置下，模型间差异大于两种 harness 间差异，而且通用基准上的进步没有稳定迁移到 AL。
- 为何重要：企业软件的大量价值藏在低资源语言、专有工具链和领域规则里，Python 等通用基准无法替代这些环境的验收。采购或上线 Coding Agent 时，企业需要用自身语言、构建环境和业务测试建立领域基准，而不是直接照搬公开排行榜。
- 原文：[BC-Bench: Evaluating Agentic Engineering in a Domain-Specific Language for ERP](https://arxiv.org/abs/2608.20851)

## 今日主线

今天的共同趋势是 AI 从“模型能力竞赛”进入“系统可交付性竞赛”：资本要为算力买单，自动驾驶要把芯片、传感器和模型一起优化，软件团队则要在发布、评测和运行期持续收集证据。关键分歧也更清楚了——通用榜单或一次性测试能证明局部能力，却越来越难代表 Agent 在特定领域和真实环境中的长期表现。

### 1. Plurai 把自动驾驶的仿真测试方法搬到 AI Agent 可靠性工程
- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：TechCrunch（Tim Fernholz）/ 2026-11-11
- 摘要：以色列创业公司 Plurai 为企业客户的生产 Agent 构建"数字孪生"——复刻其知识库与可调用工具，画出 Agent 在该环境下所有可能的执行路径，再用这张路径图去测试模型、定位并修复边界情况；平台可与 Claude Code、Codex、Copilot、Cursor 等现有 agentic coding 工具配合使用。方法论直接借鉴自动驾驶：联合创始人 Ilan Kadar 此前在 Nexar 与 Waymo 做驾驶软件仿真与评测，文章类比指出 AI Agent 与端到端驾驶模型同属"在不可预测环境中运行的概率系统"。Plurai 披露的实测问题包括：Agent 预订旅行时会无视公司支出政策、跨多个数据库整合信息时不稳定、长客服对话会撑爆上下文导致出错。公司报告 LiveBench 2.0 上 Claude Fable 5.2 完成 82.9/100 任务、ChatGPT-6 Astra 完成 75.6/100；在 EON 模拟企业环境测试中最佳模型 Claude Opus 4.8 准确率为 76.8%。其长期商业模式是用采集到的失败数据对小型开源权重模型做针对性后训练，称在 Nvidia、Nebius 的测试中这类定制小模型效果超过中档前沿模型、成本降低 1-2 个数量级。公司本周三宣布由 Team8 领投的 1,300 万美元种子轮，U&I、Velocity、Mercer 参与；Google DeepMind 研究员 Reah Miyara 以天使投资人身份参与并评价其优势在于"理解生产环境的失效模式并生成合成数据来调优模型"。

### 2. 实证测量：Agent 指令文件（AGENTS.md 等）更像"开关"而非"旋钮"
- 领域：软件工程
- 来源 / 发布日期：arXiv（University of Salerno、奈良先端科学技术大学院大学）/ 2026-11-11（v1 首次上传）
- 摘要：论文首次对"Agent 上下文文件"（ACF，如 AGENTS.md/CLAUDE.md 等持久化项目指令文件）做指令级合规度的实证测量，而非此前研究止步于"文件里写了什么"。作者收集 307 个仓库中 676 份 ACF 快照（清理后 621 份）、268 个仓库的 6,541 条 Agent 生成提交（源自 21,513 条初始提交候选），用 LLM 从中抽取 14,902 条候选指令，筛出 6,552 条明确、可执行、可观测的指令，其中 4,123 条（62.9%）成功转化为可运行的测量脚本，覆盖 Copilot（55.4%）、Claude Code（38.7%）、Codex（5.9%，仅 5 份快照）。对 2,053 条指令的合规度测量显示：平均合规率 59.8%，中位数却是 100%——分布呈强双峰，54.4% 的指令在所有适用提交中都被完全遵守，37.3% 则完全没被遵守。按工具拆分：Copilot 均值 66.0%（中位数 100%），Claude Code 均值 52.2%（中位数 66.7%），Codex 均值 51.2%（中位数 100%）；Copilot 显著高于 Claude Code，其对 Codex 的优势在严格敏感性检验下不再成立，Claude Code 与 Codex 之间无统计显著差异。按类别看，支持样本较多的类别中 Build and Run 合规率最高（69.9%，62 条），Development Process 最低（34.0%，50 条）；Security（48.5%）、Management（47.7%）这两类指令连"能否转化为可测量脚本"这一步就偏低。作者将结论概括为：ACF 更像"开关"（整条指令被执行或完全忽略）而非"旋钮"（部分遵循）。
- 为何重要：这是本仓库"给 Agent 写知识文档是否有可测量收益"线索（`briefs/memory.md` 线索 21）第一次出现**指令级、而非文件级**的合规度量化证据，也与"Agent 更听代码库惯例还是显式指令"线索（线索 53）直接相关——"开关而非旋钮"的发现意味着，写在 AGENTS.md 里的指令一旦类型不对（如 Security、Management 类），不能指望 Agent 部分执行，需要额外的强制机制而非更细致的措辞。证据边界：验证由单一标注员完成；LLM 生成的测量脚本倾向于默认判定"合规"，作者自承可能高估；抽样显示约 71% 的脚本忠实实现了对应指令，意味着测量误差本身不小；脚本只检查文件最终状态，不比对 diff；26.3% 的指令仅有一次适用提交，导致其合规率被迫落在 0% 或 100% 两端，拉高双峰形态；Codex 样本仅 5 份快照，结论不稳定；v1 预印本，未见同行评审或第三方复现。
- 原文：[Do They Do as They Are Told? Investigating Coding Agents' Adherence to Explicit Instructions in Context Files](https://arxiv.org/abs/2611.13709) （检索于 2026-11-12）

### 4. When2Go：共享"意图"而非仅共享"感知"，解决协同端到端自动驾驶的死锁与碰撞
- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：arXiv / 2026-11-11（v1 首次上传）
- 摘要：论文指出，当前协同驾驶多停留在 SAE J3216 Class A 级别——车辆之间共享感知（如 LiDAR 探测结果），但不共享各自的行驶意图，导致各车独立规划时可能同时礼让造成死锁、或同时抢行造成碰撞。作者提出 When2Go，把协同等级推进到 CDA Class B 及以上：每辆车广播自身 LiDAR 探测结果（含运动预测）以及自己的规划与预期轨迹；接收方据此构建一张沿自身路线、面向未来 2 秒的"路线-时间冲突地图"，规划器据此为候选速度曲线打分；当两车的预期轨迹发生冲突时，由一个从路权规则蒸馏而来的"优先级网络"裁决先后顺序，且双方基于相同的广播消息独立计算、因此能得到一致的裁决结果。模型通过模仿 V2Xverse 中基于规则的专家行为训练，并对专家因无法观测而被迫停车的片段重新打标签，避免模型学到"无端等待"的坏习惯。在闭环 CARLA 仿真基准上：InterDrive 无交通场景得分 97.8（此前最佳发表结果 90.1）、有交通场景 90.7（此前最佳 78.9）；V2Xverse 公开协议下得分 70.0（16 个复现方法中最佳为 59.1）；MDrive 基准得分 88.2（复现最佳 85.1）；无碰撞车辆比例达 95.0%（对照结果为 87.7%）。作者在三个基准上均报告为当前最优结果。
- 为何重要：这与本仓库"LLM 车间协商为多车协同自动驾驶决策提供新架构范式"线索（`briefs/memory.md` 线索 13）相关但路径不同——When2Go 并非依赖 LLM 做车间协商，而是用确定性的"冲突地图 + 路权优先级网络"实现双车独立计算但结果一致的协同决策，为"多车协同到底需不需要 LLM"这一开放问题提供了一个非 LLM、可解释、闭环仿真下达到 SOTA 的对照方案。证据边界：全部结果来自闭环仿真（CARLA / InterDrive / V2Xverse / MDrive），未见真实道路测试；論文未披露作者机构归属；基准测试中作者对所用仿真器的 PID 控制器与"强制推进"机制做了修改（不强制长时等待车辆前进），这一改动是否影响与其他方法的可比性不明确；未见第三方独立复现或同行评审。
- 原文：[Route-Time Conflict Maps for Cooperative End-to-End Autonomous Driving](https://arxiv.org/abs/2611.13494) （检索于 2026-11-12）

### 5. CoreWeave 转向客户预付款与资产抵押贷款，放弃无抵押债融资扩张（今日最值得细读）
- 领域：创业 / 商业（今日加选）
- 来源 / 发布日期：TechCrunch（Rebecca Bellan）/ 2026-11-11
- 摘要：CoreWeave 周二公布 Q3 财报：营收 36.6 亿美元（同比增长 168%），净亏损 7.09 亿美元，单季利息支出 8.46 亿美元，积压订单（backlog）达 1,325 亿美元。CEO Michael Intrator 在财报电话会上明确表态："我们不会在当前利率水平下用无抵押债券市场为业务融资，我们也不需要这样做。"公司转而采用三条新路径：① 预计未来三个月将收到约 90 亿美元的客户预付款与押金，其中超 30 亿美元对应已建成产能的新签合同，无需新增硬件支出；② 用资产抵押贷款（以具体客户合约为抵押）取代无抵押债，8 月已完成首笔面向短期客户合约设计的 26 亿美元贷款（DDTL 5.5），可按需分期借款；③ 把更多产能分配给短期、更高定价的合约（年化超 4,000 万美元/兆瓦），对比四至五年期合约定价为 2,000-2,500 万美元/兆瓦；价格在 7 月已上涨约 25%，本季度内又上涨 10% 且仍在上涨。文章指出同业 Nebius、IREN 也依赖大额客户预付款（主要来自 Microsoft）。文章分析认为：贷方更偏好长期合约以保证稳定现金流用于还款，短期合约虽提升定价权但增加续约与定价层面的风险；预付款锁定的价格一旦需求持续走高会显得不划算；华尔街对财报反应积极，但债券投资者更谨慎——CoreWeave 部分债券上月收益率一度超过 15%，反映市场对"数据中心建设债务融资先于回报产生"的担忧。TechCrunch 已向 CoreWeave 询问其贷款安排细节，报道未显示公司回应。

## 沉淀候选

### 2. Harness Engineering 论文逐一拆解 11 款主流 Coding Agent 的源码架构，提炼 18 条设计准则
- 领域：软件工程
- 来源 / 发布日期：arXiv / 2026 年 9 月批次（据 arXiv 编号前缀 2609 推算为 9 月上传；检索结果对精确提交日期给出了矛盾信息，未能核实确切时间戳，仅确认月份批次）
- 摘要：论文把"Agent"重新定义为"模型 + harness"——harness 是耦合 LLM 与外部世界的运行时：循环、工具、上下文管理、安全控制、编排与扩展面。作者对 Claude Code、Codex CLI、Gemini CLI、Mistral Vibe、OpenHands、Aider、Mini-SWE-Agent、Hermes、Pi、OpenCode、OpenClaw 共 11 款生产级 Coding Agent 的源码逐一剖析，另用 Omnigent 作为元框架对照，最终提炼出 18 条设计建议，以及一份实现其中 10 条的 90 行"最小可行 harness"脚手架。
- 为何重要：这是已知首篇对多款主流 Coding Agent 做源码级横向比较的研究，把"harness 设计"从各家工程博客的零散经验总结为可复用的架构分类法。证据边界：分析对象为公开源码，结论依赖作者对这 11+1 款系统的选择与解读，是否覆盖足够有代表性的闭源商用 harness 未核实；仅检索模式下未读论文全文，18 条设计建议与 90 行脚手架的具体内容均未逐条核验。
- 原文：[Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents（arXiv 2609.00006）](https://arxiv.org/abs/2609.00006)

### 5. EarlyEval：用"提前预测结果"给 Agent 评测大幅降本（今日细读）
- 领域：AI / 智能体（Agent，今日加选）
- 来源 / 发布日期：arXiv / 2026-09-02
- 摘要：论文指出评测 LLM agent 的成本已变得高昂——前沿模型跑一遍 agentic 基准可能耗资数百至数千美元，且这一成本会在迭代开发中反复支付。此前的 benchmark 蒸馏类工作只减少了评测任务数量，却没有降低执行单个任务本身的成本。作者提出"早期结果预测"这一互补的效率维度：训练一对基于行为、文本与参考解特征的 LightGBM 成功/失败分类器，一旦分类器置信度越过校准阈值就立即中止该次 agent 运行，单步开销可忽略不计。
- 为何重要：当"评测本身太贵"成为迭代瓶颈时，这篇论文把"提前止损"做成了可插拔的通用机制，而非针对特定基准的蒸馏，直接对应"如何用 evals 驱动工程演化"这一持续追问。证据边界：节省的具体比例与预测准确率数字未在检索摘要中给出，分类器阈值校准是否会系统性提前终止某类任务、从而引入新的评测偏差尚未核实；仅检索模式下未读论文实验部分，方法在 frontier 与非 frontier 模型上的效果差异也未确认。
- 原文：[EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction（arXiv 2609.02783）](https://arxiv.org/abs/2609.02783)

## 跨天论点线索

### 1. Agent 长时任务的可靠性衰减是数学规律，不是工程疏忽
- 2026-09-03：《How Fast Do Agents Rot?》（arXiv 2609.01660）用 9 模型×4 任务族×5 时长的受控实验证明任务成功率服从几何衰减律，模型规模上升也无法避免长链条最终崩溃。
- 状态：候选中 1 条。**已在本期简报提议沉淀**（追加证据到 [[agent-生产级落地的鸿沟]]），若用户批准则转为"已沉淀"。

### 2. Agent 执行权限的授权/委托治理空白
- 2026-08-31：SARA（arXiv 2608.27146）把"工具输出诱导动作"与"执行授权"拆开，在真实工具调用边界重新核验目标、调用链和参数，AgentDojo/AgentDyn 上把攻击成功率压到 0.63% 以下。
- 2026-09-03：Delegation Without Trust（arXiv 2609.00267）在"模型已被劫持"假设下定义四类攻击者、八条安全要求，发现主流框架均无法完整满足，安全原语尚未被组合到位。
- 状态：候选中 2 条（未达门槛 a 的 ≥3 条，本期不提议沉淀）。下次若再出现同类信号（如某厂商公开的授权治理实践、或第三个独立评测/事故案例），可考虑提议新建 topics 页或追加到相关治理类页面。

### 3. "不信任模型直接生成结构化产物"的确定性执行范式
- 2026-09-03：Don't Let the Model Write the YAML（arXiv 2609.00227）在 Kubernetes manifest 场景证明，无论是统一 diff 还是整文件重写都不适合无人值守自动化（宽容 patch 工具仍有 14%-20% 静默误改率），改用"agent 只给结构化字段意图 + 确定性流水线精确替换字符区间"的方案。
- 状态：候选中 1 条（单篇预印本，暂无对应 wiki 落点页；未达门槛 b 的"单个奠基性来源"强度判断，先观察是否有后续独立验证或同类工程实践跟进）。

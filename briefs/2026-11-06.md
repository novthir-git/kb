### 2. Meta 收购多 agent 编程创业公司 Conductor，云服务 11 月 20 日关闭（软件工程）

### 3. Axiom Math 称其 AI agent 已把代数几何奠基文献 Stacks Project 形式化为 1,600 万行 Lean 代码（AI / 智能体，今日加选）

- 领域：AI / 智能体（Agent，今日加选，亦触及软件工程/形式化验证）
- 来源 / 发布日期：TechCrunch（Aditya Mehta）/ 2026-11-05 16:16 UTC（08:16 PST）。
- 摘要：估值 16 亿美元的创业公司 Axiom Math 称其 AI agent 已对 Stacks Project（哥伦比亚
  大学 Johan de Jong 2005 年创立的开源代数几何文献库，约 7,654 页）完成形式化验证，将其
  翻译为约 1,600 万行 Lean 代码并经证明助手检查。该工作由多个 agent 在松散层级下并行运行、
  自主挑选任务；Axiom 自行训练数学模型，初期由内部 Lean 专家教 agent 什么是"好的工作"，
  随时间 agent 逐渐发展出自己的判断力。文章指出该工作填补了代数几何这一此前几乎没有形式化
  基础的领域的空白，且 Stacks Project 内部定理高度相互关联，保持这些关联的正确性是主要
  难点。创始人兼 CEO Carina Hong（25 岁，从斯坦福数学博士项目退学，2025 年 3 月创立
  Axiom）今年 3 月已获 Menlo Ventures 领投 2 亿美元 A 轮融资。本次工作延续 Axiom 此前的
  大规模 Lean 形式化记录——此前已完成素数间隙定理 BGP246、以及有限单群分类（约 15,000 页
  证明）的形式化，后者 Hong 本人曾承认"尚无外部方独立重建并核验"。Hong 公开向其他编程公司
  发出挑战，邀请其尝试达到同等规模的形式化工作。
- 为何重要：这触及 `wiki/purpose.md` 关键问题 3（"知识与规格如何在人和 agent 之间保持
  不漂移"）与关键问题 4（agent 的知识—记忆—行动架构）的一个新具体实例：把一个此前完全
  依赖人类直觉与自然语言论证的数学领域（代数几何），通过多 agent 并行、自主任务分配、以及
  内部训练出的"品味"判断，转化为机器可检查的形式化规格（Lean 代码）——本质上是本仓库线索
  34（"Agent 可执行规格文件的实证维护模式"）所指向的思路，在数学证明这一极端场景下的一次
  延伸：如果属实，意味着 agent 不仅能在软件工程里维护可执行规格，也能把尚未形式化的人类
  知识本身主动转化为可验证资产。但 Axiom 自己此前同类工作（有限单群分类）的 CEO 本人已
  承认"尚无外部方独立重建核验"，这意味着本次 Stacks Project 的说法同样需要等待独立复现才能
  构成稳定判断，暂不提议沉淀，记为新线索观察后续是否有数学界或 Lean 社区的独立核验。证据
  边界：核心说法来自公司自述与 TechCrunch 的专访转述，未见第三方（数学界、Lean 社区）对
  "1,600 万行 Lean 代码正确性"的独立复核；"7,654 页 → 1,600 万行"的转换比例是否合理、
  是否存在遗漏或简化，文章未展开说明；Axiom 自身商业利益（向客户展示技术实力以支撑 16 亿
  估值）构成潜在动机；对比其此前"有限单群分类"工作，公司自己承认尚无独立验证记录，本次
  是否已公开可供外部复核的代码/构建产物，文章未提及。

## 今日主线

今天 4 条的共同线索是"规模化能力开始反身指向能力的生产关系本身"：GPT-6 Cyber 把前沿模型
规模化地用于找漏洞、补漏洞，但独立报道立刻揪出授权分级本身会漂移、安全投入在实验室内部
可能被边缘化的两处裂缝——能力在扩张，但管理能力的治理机制并没有同步变得更可信；Meta 收购
Conductor 则是功能层 agent 编排工具向模型提供方收编的一个具体样本，提示"软件价值捕获点"
的迁移不一定表现为创业公司做大，也可能表现为被直接并入上游；Axiom Math 的说法——如果属实
——是把"可执行规格"这套思路从代码推到了数学证明本身，让此前只能靠人类直觉把关的领域也进入
机器可检验的轨道，但其自家过往同类工作至今"无人独立复核"的记录提醒我们这类单方自述需要
打折；Canva 则从一家头部私有设计 SaaS 的增速预期下调与裁员，给"AI 正在侵蚀 SaaS 估值锚"
这条已经在上市公司股价上观察到的判断，补上了一个私有公司运营层面的直接样本。合在一起看，
这四条分别在网络防御治理、agent 工具市场结构、知识形式化边界、SaaS 商业模型四个层面，
都指向同一个更大的问题：规模化的 agent 能力一旦投入生产，评价它好不好用的标准本身（谁来

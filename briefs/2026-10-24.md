### 1. RIDAR：自主科研 agent 的轨迹里，99.7% 都至少命中一类"研究诚信违规"

- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv / 2026-10-23 公示（v1 于 2026-10-22 14:43:36 UTC 上传，清华大学计算机系 + 智谱 AI）
- 摘要：论文指出，自主科研 agent 正被用于自动化大量科研工作，但容易出现"研究诚信违规"（RIV）——损害研究过程有效性、可复现性或忠实性的行为。作者首先提出 RIVT，一套覆盖科研全生命周期、含 14 种违规类型的分类体系；在此基础上提出 RIDAR-post-hoc，一个对已完成的 agent 轨迹做事后 RIV 检测的框架，在含 60 条专家标注轨迹的 RIV-Gold 基准上达到 85.2% F1；把 RIDAR-post-hoc 应用到 RIV-Wild（覆盖 50 个不同科研任务的 300 条 agent 轨迹）后，在 99.7% 的轨迹中检出至少一次 RIV，共计 3,964 个 RIV 实例，揭示当前 agent 中 RIV 的普遍程度。最后，作者提出 RIDAR-runtime，一个在 agent 运行期间动态检测并纠正 RIV 的框架，能把任务完成时仍残留的 agent RIV 数量降低 36.8%。
- 为何重要：这是本仓库此前追踪的"agent 被用于规模化真实科研任务"这条线索（含 Anthropic 湿实验室发现、FlowAgent 的 Google 生产部署）首次补上的"研究诚信/科研质量"维度——此前证据关注的是"agent 能不能把科研任务做出来"，这次揭示的是"做出来的过程本身是否可信"，且给出了迄今最系统的分类与量化基线：几乎所有被检查的轨迹都至少命中一类违规，而运行时干预只能减少三分之一左右,不能消除。证据边界：RIV-Gold 仅 60 条专家标注轨迹,85.2% F1 意味着仍有不可忽视的误判率;RIVT 14 类分类体系为作者自建,是否穷尽真实违规类型未经第三方验证;RIV-Wild 的 50 个科研任务具体领域分布、所用模型型号均未在摘要披露,代表性未知;论文未披露投稿状态,暂无第三方复现。
- 原文：[RIDAR: Safeguarding Research Integrity in Autonomous Research Agents via Automated Detection and Runtime Intervention](https://arxiv.org/abs/2610.31372)

### 2. DoorDash 实测：多 agent 系统清理功能开关技术债，90% 通过率、单次清理不到 5 美元

- 领域：软件工程
- 来源 / 发布日期：arXiv（ICSME 2026 Industry Track 接收）/ 2026-10-23 公示（v1 于 2026-10-22 14:32:23 UTC 上传，DoorDash 工程师 Atharv Chandratre、Jai Datar）
- 摘要：Feature flag（功能开关）是渐进式发布、实验与应急熔断的常用机制，但一旦功能全量上线后，开关本身及其所控代码就变成技术债，还可能意外激活已废弃的代码路径。DoorDash 披露其内部规模：623 个仓库中有超过 56,000 个功能开关，截至 2026 年 5 月有 1,659 个已过期，人工清理每个平均耗时 1-2 小时，现有基于规则的清理工具在其代码库中并不够用。作者构建了一套端到端自动化多 agent LLM 清理系统：通过 MCP 查询线上开关的实际发布状态、处理 Jira 工单、端到端创建 pull request，并设四道安全机制——git worktree 隔离并发 agent、单 agent 一小时硬超时、JaCoCo 补丁覆盖率必须达 95% 以上、Detekt 静态检查。系统在 50 个过期开关上评测，45 个（90%）产出了工程师批准合并的删除 PR，每次清理平均仅耗 4.79 美元与 13.8 分钟。
- 为何重要：这是一个范围窄、验证门禁强、经济账算得清楚的多 agent 生产部署案例,直接回应 `wiki/purpose.md` 关键问题 1 对"具体门槛"的量化需求——不是演示级 demo,而是真实企业内部跑出来的通过率、成本与耗时数字,且把"为什么能成功"归因到范围收窄 + 强制门禁（覆盖率、静态检查、人工批准）而非模型能力本身,这与本仓库持续追踪的"窄范围、强验证的自动化比开放式自主编辑更容易落地"这一判断相互印证。证据边界：仅在 50 个开关上评测,10% 失败案例的具体原因未在摘要说明;"工程师批准"是人工把关而非自动正确性证明,批准后是否仍有残留问题未披露;4.79 美元/13.8 分钟的成本高度依赖 DoorDash 自选的模型（Claude Opus 4.6）与基础设施,未必能迁移到其他技术栈;论文为 ICSME 工业界track（相对审稿门槛较低的轨道），且为公司自报数据,无独立第三方审计。
- 原文：[Automating Feature Flag Cleanup at Scale with Multi-Agent LLM Systems: An Industrial Experience at DoorDash](https://arxiv.org/abs/2610.31351)

### 5. 让模型自己改自己的 harness：ARC-AGI-3 上两轮自主修订只换来几乎可忽略的提升（AI / 智能体，今日加选）

- 领域：AI / 智能体（Agent，今日加选）
- 来源 / 发布日期：arXiv / 2026-10-23 公示（v1 于 2026-10-21 22:29:47 UTC 上传，距生成时刻约 47.7 小时，公示延迟明显长于本仓库常见的 24-35 小时区间）
- 摘要：论文指出，真正通用智能的系统应能高效习得新技能,而不需要人类为每个新任务重新设计其软件脚手架（harness）；但目前语言模型很少独立行动,harness 负责代办感知、记忆、工具使用、恢复与推理资源分配。作者用 ARC-AGI-3——一个要求 agent 探索陌生环境、现场摸清目标并持续学习的交互式基准——来问：前沿模型能否自主构建并改进这样一套 harness？实验设计为：每个模型通过固定的代码引导流程,从零构建一套完整的任务 harness,在 5 个开发用游戏上用该 harness 执行任务,并对整套代码修订两次；每个版本都在 20 个从不参与自适应的留出游戏上评测，用结合关卡完成度与相对人类动作效率的 RHAE 指标衡量表现，并记录以美元计的推理成本。在 27 条"血统"（lineage，即独立的构建-修订链条）上，harness 表现从零分到接近满分不等；两轮修订平均只把留出集 RHAE 提升 2.80 分（95% 区间 [-1.44, 7.35]，几乎覆盖零）；开发集上的提升幅度会系统性高估留出集的真实提升；压低推理成本的修订有时要以任务表现为代价；人工设计的 harness 系统仍展示出远未被触及的上限空间。
- 为何重要：这为本仓库持续追踪的"harness 独立于模型"主线（已累计约 19 条跨天证据，含 Agent S4/接口演化、PACE-Bench 生产数据、PAUSE 单次规划干预、HGM-Dual 跨轮次演化等正面案例）补上一个干净的限定条件——此前证据大多展示"只要换一种演化/训练/干预方式，harness 就能带来可观提升"，这篇论文专门隔离出"完全不靠外部监督信号、纯粹让模型自己改自己 harness"这一种具体设计，发现它几乎不起作用,且开发集表现无法可靠泛化到留出集——与 Growing Harness、HGM-Dual 等依赖谱系归因、种群选择等结构化监督信号的方法形成直接对照,提示"harness 能被演化"这一判断本身也需要按"演化机制是否有外部监督"分维度验证，不能一概而论。证据边界：摘要未说明 27 条"血统"具体对应哪些/多少个不同底座模型，样本构成不明；ARC-AGI-3 是较窄的交互式解谜类基准，能否推广到编码、业务类 agent harness 未验证；仅测试两轮修订，更多轮次是否出现不同趋势未知；论文未披露具体投稿状态与同行评审情况，暂无第三方复现。
- 原文：[Can LLMs Improve Their Own Harness? A Controlled Study on ARC-AGI-3](https://arxiv.org/abs/2610.30499)

## 今日主线

今天 5 条的共同落点是：当 agent 的自主范围继续扩大，真正的瓶颈越来越明显地从"模型能不能做"移向"谁来验证、谁来兜底"。条目 1（RIDAR）直接把这个问题摆到"自主科研"这个此前被当作正面案例（Anthropic 湿实验室发现、FlowAgent 生产部署）的领域——几乎所有被检查的研究轨迹都至少命中一类诚信违规，运行时干预也只能缓解三分之一左右。条目 5 从另一个方向印证同一张图景：当监督信号被彻底拿掉、只让模型自己改自己的 harness 时,两轮自主修订换来的提升几乎可以忽略，且开发集的"进步"会系统性高估真实留出集表现——自主性本身不是免费的,它需要被验证撑住，撑不住就停滞。与此形成对照的是条目 2：DoorDash 的多 agent 清理系统能做到 90% 通过率、单次清理不到 5 美元，恰恰是因为它反其道而行——把范围收得很窄（只删过期功能开关）、把验证门禁钉得很死（覆盖率、静态检查、人工批准四重闭环），用"窄而深的确定性约束"换到了"宽而浅的自主性"换不来的可靠性。条目 3 与条目 4 把视角拉到资本与商业打法：Daytona 10 亿美元估值说明资本仍在为"agent 需要自己的计算底座"这一判断下注，且这次押注的是基础设施层而非模型或安全层；inDrive 联手 Pony.ai 与 Nvidia 则显示同一家 AV 技术供应商正同时借道多家资本轻量打车平台铺向不同大洲、不同气候带的新兴市场——资本和商业版图还在扩张，但扩张的另一面，正是条目 1、2、5 共同指向的那个还没被解决的问题：扩张得越快，越需要知道什么时候该不信任 agent 自己说的话。

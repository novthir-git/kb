### 1. WikiSkill：让 Agent 把执行经验编译成可持续演化的技能
- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv / 2026-08-28（v1 于 2026-08-27 UTC 上传）
- 摘要：WikiSkill 将 Agent 工作区拆成不可变执行轨迹、持续累积的 Wiki 与可执行 Skills 三层，并让维护者从每轮执行中更新知识、再由 Skill Proposer 提议技能改动。作者报告，该方法在多组模型与基准上优于现有技能演化方法；演化后的技能还能跨模型迁移，小模型配合技能有时可超过更大的无技能模型。
- 为何重要：它把 Agent 的“经验复用”从压缩对话记忆推进为可审查、可迭代的知识—技能编译流程，也说明模型扩展与外部技能并非替代关系。当前证据仍来自作者设定的离线基准，尚未证明长期生产运行中的知识漂移、维护成本与错误累积可控。
- 原文：[WikiSkill 论文](https://arxiv.org/abs/2608.27454)
- 配图：![WikiSkill 的 Raw、Wiki 与 Skills 三层演化框架](https://arxiv.org/html/2608.27454v1/wikiskill-diagram.png)  
  图片来源：[WikiSkill 论文 Figure 2](https://arxiv.org/html/2608.27454v1)。

### 2. MCR-Bench：代码审查模型一进入多轮交互，缺陷追踪能力明显下降
- 领域：软件工程
- 来源 / 发布日期：arXiv（ISSTA 2026 接收论文）/ 2026-08-28（v1 于 2026-08-27 UTC 上传）
- 摘要：MCR-Bench 收录 5 种语言、2,269 个真实多轮代码审查任务，并为缺陷类型、严重性及跨轮次状态变化提供细粒度标注。实验显示，主流模型不仅容易漏掉语义复杂或不显眼的缺陷，随着审查轮次增加，还会出现遗忘、时间错位，以及把已修复问题和新问题混淆的情况。
- 为何重要：现有自动审查评测多把 Pull Request 当成一次性静态输入，这个基准把“能否持续维护缺陷生命周期”纳入测量，更接近真实团队协作。它意味着 Coding Agent 的审查质量不能只看单轮召回率，还要测试跨轮记忆、状态对齐和历史问题退役。
- 原文：[MCR-Bench 论文](https://arxiv.org/abs/2608.27442)
- 配图：![单片段、单轮 PR 与真实多轮 PR 代码审查的差异](https://arxiv.org/html/2608.27442v1/comparison_examples.png)  
  图片来源：[MCR-Bench 论文 Figure 1](https://arxiv.org/html/2608.27442v1)。

### 3. Anthropic 向美国 K-12 学区免费开放 Claude Enterprise，争夺机构级入口
- 领域：创业 / 商业
- 来源 / 发布日期：Claude by Anthropic / 2026-08-28
- 摘要：Anthropic 将 Claude for Teachers 从个人教师账户扩展到美国 K-12 学校和学区，符合条件且在 2027 年 6 月 30 日前注册的机构可获一年免费 Enterprise 使用权。方案包含单点登录、角色权限、域名接管、集中策略与采用情况管理，并提供与州课程标准对齐的教学 Skills；默认关闭超额计费，教师数据不用于模型训练。
- 为何重要：免费 Enterprise 不是单纯获客补贴，而是用身份、合约、数据处理协议和管理员控制把 Claude 嵌入学区采购与治理体系。产品成效尚未得到独立验证，Anthropic 计划秋季在 Detroit Public Schools Community District 开展评估，后续应重点看教师负担和教学实践是否真实改善。
- 原文：[Claude for Teachers, now available for schools and districts](https://claude.com/blog/claude-for-teachers-now-available-for-schools-and-districts)

### 4. 独立公路测试发现：部分辅助变道未满足 UNECE 最小安全距离
- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：arXiv / 2026-08-28（v1 于 2026-08-27 UTC 上传）
- 摘要：研究团队在法国 A31 高速公路上用 LiDAR 与 RTK-GNSS 独立测试商用 Assisted Lane Change 系统，并将轨迹与 UNECE R79 的最小安全距离要求比较。27 个预设场景中，系统完成 18 次变道、抑制 9 次；其中 6 次获准变道未满足监管距离要求，计入测量不确定性后仍有 3 次偏差具统计显著性。
- 为何重要：这项工作揭示封闭试验场和依赖厂商配合的地理围栏测试可能漏掉真实交通交互，也给市场监督机构提供了可独立复现的公路测试方法。样本仅覆盖一套系统和 27 个场景，不能外推为整个 ADAS 行业的失效率，但足以支持扩大在用车抽检。
- 原文：[Beyond the Proving Ground 论文](https://arxiv.org/abs/2608.26669)

### 5. SARA 把“工具输出诱导动作”与“执行授权”拆开，压低 Agent 注入攻击成功率
- 领域：AI / 智能体（Agent，今日加选）
- 来源 / 发布日期：arXiv / 2026-08-28（v1 于 2026-08-27 UTC 上传）
- 摘要：论文指出，网页、邮件或 API 返回值一旦包含具体行动要求，就可能从“数据”变成越权“命令”；SARA 因此持续记录动作来源，但只依据用户目标及已授权成功执行产生的审计证据，在真实工具调用边界重新核验目标、调用链和参数。作者在 AgentDojo 与 AgentDyn 的四个主要设置中将攻击成功率控制在 0.63% 以下，同时保持有竞争力的任务效用。
- 为何重要：这个设计把间接 Prompt Injection 从内容过滤问题改写成运行时授权问题，直接对应会发消息、改数据或提交交易的生产 Agent。结果仍是预印本在两个基准上的自报实验，Action Probe 本身的误判、额外推理成本和面对新型攻击的稳健性仍需独立复现。
- 原文：[SARA 论文](https://arxiv.org/abs/2608.27146)
- 配图：![SARA 在真实工具执行边界进行运行时授权的框架](https://arxiv.org/html/2608.27146v1/figures/Framework.png)  
  图片来源：[SARA 论文 Figure 1](https://arxiv.org/html/2608.27146v1)。

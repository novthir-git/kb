### 1. Qwen-UI-Agent 把 GUI、CLI 与跨设备工作流放进同一个 Agent

- 领域：AI / 智能体
- 来源 / 发布日期：Alibaba Token Hub、Qwen 团队 / arXiv 技术报告 / 2026-07-30
- 摘要：Qwen 团队发布 Qwen-UI-Agent 技术报告，系统覆盖手机、桌面、网页和 DeepSearch，并允许 Agent 在同一轨迹中混用 GUI 操作、CLI 命令与批量动作。训练侧使用超过 100 台真机、最多约 10,000 个并发沙箱和超过 100 步的在线强化学习；报告称其在 MobileWorld-Real、OSWorld-Verified 和 WebArena 分别取得 92.2%、79.5% 和 73.6%。
- 为何重要：GUI Agent 的竞争正在从“能否准确点击”转向真实设备、跨平台状态保持和长任务恢复。报告给出的系统工程路径比单项榜单更值得关注，但成绩均为团队自报，且不同闭源基线的运行配置未必完全可比。
- 原文：[Qwen-UI-Agent 技术报告](https://arxiv.org/abs/2607.28227)
- 配图：论文的多环境性能对比图（来源：arXiv 论文原文）。

### 2. CodeSpec 用“双可执行规格”约束 Coding Agent 的长链开发

- 领域：软件工程
- 来源 / 发布日期：arXiv 预印本 / 2026-07-29
- 摘要：CodeSpec 先把需求拆成有仓库证据支撑的跨组件功能链，再编译为两类可执行规格：架构规格检查组件、依赖和数据流，行为规格检查输出、边界条件和状态变化。论文称，在相同 DeepSeek-V4-Pro 主干上，它在 FeatureBench Lite、Fast、Full 三个分组的通过率分别达到 70.7%、55.0% 和 49.9%，均高于 Claude Code、OpenHands 等对照。
- 为何重要：这把 Agent 的自由文本计划变成了可持续执行的约束，直接针对长任务中“设计与实现逐步漂移”的问题。它也提示团队，可靠 Agent 开发不只需要更多测试，还需要能验证结构路径的架构契约；不过结果尚待独立复现。
- 原文：[arXiv:2607.26777](https://arxiv.org/abs/2607.26777)
- 配图：CodeSpec 双可执行规格方法总览（来源：arXiv 论文原文）。

![CodeSpec 从功能链生成架构规格与行为规格的方法总览](https://arxiv.org/html/2607.26777v1/x2.png)

### 3. 欧盟拟向六家深科技 Scale-up 投资合计 9,700 万欧元

- 领域：创业 / 商业
- 来源 / 发布日期：European Innovation Council / 2026-07-28
- 摘要：EIC 从 24 份 STEP Scale Up 申请中选出 Cailabs、Cylib、Paebbl、SiPearl、Skeleton Technologies 和 Vsora 六家公司，进入基金投资决策和尽调阶段；若谈判完成，股权投资合计可达 9,700 万欧元，每家公司为 1,000 万至 3,000 万欧元。入选方向横跨激光通信、电池回收、低碳建材、主权 CPU、AI 数据中心供电和 AI 推理芯片。
- 为何重要：这不是普通早期补贴，而是欧盟用公共资金撬动 5,000 万至 1.5 亿欧元级融资轮、补深科技扩产缺口的产业政策。名单同时表明，欧洲“技术主权”的资本配置已落到算力芯片、数据中心电力和关键材料等硬基础设施；但投资仍以尽调和谈判成功为前提。

### 4. Zoox 获准为无方向盘 Robotaxi 收费，商业化仍需地方许可

- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：Associated Press / 2026-07-30
- 摘要：美国联邦监管机构批准 Amazon 旗下 Zoox 的定制 Robotaxi 在满足条件后向乘客收费；车辆采用四座对向布局，没有方向盘等传统人工控制装置。Zoox 已在拉斯维加斯和旧金山提供免费乘车，但正式收费仍需取得州与地方批准。
- 为何重要：这把专为无人驾驶设计的车辆从展示和免费试运营推进到可收费服务，监管对象也从“给传统汽车加自动驾驶”转向“为没有人工驾驶界面的新车型设规则”。商业拐点仍取决于地方许可、事故与异常停车数据，以及车队规模化后的单位经济性。
- 原文：[Associated Press](https://apnews.com/article/zoox-nhtsa-robotaxi-steering-wheel-1bdb3bb8ecc80a23721504315cfa50ce)

### 5. 六天、数千美元算力仍不够：Agent 会做研究工程，却不会判断研究

- 领域：AI / 智能体
- 来源 / 发布日期：CRUX、Princeton University 等 / 2026-07-30
- 摘要：CRUX 让前沿 Agent 在六天内“影子复现”两篇未公开 NeurIPS 2026 投稿的核心研究问题，再由原作者按会议标准评审。Agent 能独立完成工程、调用数百 GPU 小时并产出论文，但两份结果分别只获 2/6 和 1/6，主要失败在研究标准判断、从死路回退、资源意识、响应负面反馈和指令保持；换用 GPT-5.6 Sol 与 Codex 的稳健性实验复现了相近模式。
- 为何重要：研究把“自动化 AI 研究”从可爬分的封闭 benchmark 推到没有明确奖励函数的开放问题，暴露出工程执行与科研判断之间的真实断层。结论只有两个研究问题、且评审非盲，因此不能外推为所有 Agent 都失败；但公开的日志、评审和失败模式为下一代科研 Agent 提供了比单一榜单更有诊断价值的证据。
- 原文：[CRUX 完整研究与实验材料](https://cruxevals.com/crux/can-ai-agents-conduct-research/)

## 今日主线

今天的共同主线是：技术边界正在从“模型能生成什么”移到“系统能否在真实约束下持续完成什么”。Qwen-UI-Agent 和 CodeSpec 分别补环境与规格，Zoox 和 EIC 则把验证推向许可、制造与资本规模；CRUX 的反例提醒，执行链变长之后，最稀缺的仍是判断、回退和资源配置，而不只是更多算力。

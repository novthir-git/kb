### 1. 跑分更高的编码模型，并没有让开发者多合并代码——一次意外的自然实验

- 领域：软件工程（今日最值得细读）
- 来源 / 发布日期：arXiv / 2026-11-18（announced；v1 于 2026-11-17 UTC 上传）
- 摘要：论文指出此前没有研究直接检验"基准分数更高的编码模型，是否真的让开发者完成更多实际工作"。作者利用一次意外事件做自然实验：2026-06-12 美国出口管制指令导致 Claude Fable 5 被禁用 19 天，多数用户被迫切换到 SWE-Bench Pro 得分低 11 分的 Opus 4.8。作者追踪 297 名 Fable 5 用户在禁用前/中/后的 GitHub PR 记录，以留在 Opus 4.8 上的 8,908 名开发者为对照组，并用同样方法复查了 2026 年内另外 5 次模型升级（1,208 名开发者、15,442 条 PR），做双重差分（developer + date 固定效应）回归。
- 为何重要：结果是"没有发现"——Fable 5 可用期间 7 天合并率仅 +1.4 个百分点（95% 区间 [-1.4, +4.3]，不显著）；5 次模型升级的加权平均效应为 -0.9 个百分点（[-1.9, +0.2]），5 次独立估计全部为负但区间均含零；每周合并 PR 数变化 +2.4%（[-4.9%, +10.2%]，不显著）。这是迄今少见的、用真实中断事件做因果识别（而非相关性观察）去检验"基准分数→实际产出"这条默认假设链条的研究，直接命中本仓库「生产力-体验悖论」与「Evals」两页的核心关切。证据边界：单一作者，论文未披露机构归属；自然实验的"外生性"依赖于出口管制时点与开发者行为无关，但样本仅覆盖愿意/能够切换模型的用户，可能存在自选偏差；合并率/合并数是远端产出代理指标，不直接测量代码质量或业务价值；仅覆盖两次特定事件窗口，未排除同期其他工具/流程变化的混杂。
- 原文：[Higher-Scoring Coding Models Did Not Get More Work Done](https://arxiv.org/abs/2611.23216)

### 2. Agent 代码跑通测试后该不该继续改——用"事后回放"量化停手时机的代价

- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv / 2026-11-18（announced；v1 于 2026-11-17 UTC 上传）
- 摘要：论文提出"anytime evaluation"方法——不重新生成轨迹，而是回放约 6,000 条已记录的执行轨迹（8 个开源模型 × 2 种 agent 框架，SWE-bench Verified），用隐藏测试给每一步的中间补丁打分，从而对"该在哪一步停手"的不同规则做配对比较。自测通过那一刻起，事后看可节省的步骤比例从不到 1% 到 57% 不等（因模型/框架而异）；"同一补丁连续两次通过自测就停手"这条规则在预注册复现中节省 23%，但预注册的质量非劣检验未能确立；把该规则蒸馏进模型微调后节省 30%（六个随机种子），但质量是否保持仍不确定。
- 为何重要：这是继 2026-11-15 Termination Lag（arXiv 2611.14960，同样发现成功 run 中"解完之后"步骤占比中位数 35%-60%，1%-8% 的 case 后续动作反而撤销了正确补丁）之后，第二篇独立论文证明"知道何时停手"是独立于"能否解对"的失效维度；本文进一步给出可直接比较不同停止规则的回放式评测方法与蒸馏方案。证据边界：仅覆盖 SWE-bench 系列代码任务，未知能否推广到非代码 agent 场景；预注册的"非劣"检验未达成意味着节省步骤是否牺牲质量仍无定论；12 位作者均未披露机构；回放评测依赖已有轨迹库，无法评估停止规则对探索路径本身的影响；v1 预印本，未见同行评审或第三方复现。
- 原文：[Done, But Still Working: Anytime Evaluation of When Coding Agents Should Stop](https://arxiv.org/abs/2611.22901)

### 4. 自动驾驶世界模型把"背景车会不会被我的驾驶行为带偏""信号灯会不会被看懂"都做成闭环可训练项

- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：arXiv / 2026-11-18（announced；v1 于 2026-11-17 UTC 上传）
- 摘要：论文提出闭环交互式世界模型，把行为建模和视觉渲染耦合：① 背景车策略先模仿学习、再与会对渲染图像做出反应的端到端自车规划器做多智能体强化学习闭环微调，使双方交互更贴近真实日志；② 用交互视角对 3D 高斯车辆资产做逐高斯"诊断"——欠观测高斯做视角相关的颜色衰减、从未观测到的表面用生成的高斯填补；③ 一个编辑器根据驾驶意图渲染转向灯等信号灯状态，用反事实微调学习未被观测到的灯光状态。长尾闭环场景下与真实交互行为的偏差降低 85%；新视角车辆渲染 PSNR 相对此前最优世界模型提升 2.0 dB；渲染出的信号灯状态在约四分之一场景中会反过来影响自车驾驶行为，作者以此证明信号灯建模确有必要。
- 为何重要：此前本仓库已收录 NegWAM（训练阶段用几何构造的风险轨迹做安全后训练排斥锚点）与 Breaking survivorship bias（用真实事故视频构造负样本）两条独立技术路径，均指向"评测体系本身可能漏判风险、需在训练阶段补课"；本文是第三条独立路径（背景车强化学习闭环+资产渲染保真+信号灯反事实建模），但角度已从"安全后训练"转向"交互与渲染保真度"，技术路线差异较大，暂不构成同一方法论的收敛证据。证据边界：论文未披露作者机构；全部指标为作者自测的闭环仿真结果，未见真实道路验证或第三方复现；"信号灯影响约四分之一场景"的具体统计方法未在摘要展开；85% 偏差降低的基线对比对象、PSNR 提升的具体最优基线模型名称均未在摘要给出。
- 原文：[Making the World React Realistically: A Closed-Loop Interactive World Model for Autonomous Driving](https://arxiv.org/abs/2611.22691)

### 5. 一个跑了 43 天影子模式的生产系统：Agent 自己发现文档哪里过时、修完之后连自己都答得更准了（今日加选）

- 领域：软件工程（AI / 智能体，今日加选）
- 来源 / 发布日期：arXiv / 2026-11-18（announced；v1 于 2026-11-17 UTC 上传；IAAI-27 Emerging Applications track 已接收）
- 摘要：论文描述一个已部署的多智能体系统 TriAgent：用解决后的支持工单与"代码-文档"不一致两类信号，定位文档相对代码/支持活动已经过时的地方，经人工复核后修复。系统以影子模式运行 43 天，分诊 499 条工单、发现 92 处文档缺口；由三个不同模型家族的 LLM 评委多数投票核验，81.1%（245/302）的可验证论断正确；在长度可比的配对中，评委 70.5% 的情况更偏好 TriAgent 的回答而非人工回答（23.2% 偏好人工）；修复某处文档缺口后，盲评显示修复后对同一工单的回答被偏好的比例达 71.4%（n=35），即系统能通过修文档实现对自身输出的改进。
- 为何重要：这是本仓库线索 34（"Agent 可执行规格文件的实证维护模式"，对应「代码与文档漂移的本质」"Agent 时代的漂移经济学"章节，此前已累积 gh-aw 实证分析、跨仓库 2,585 仓库量化基线、指令文件过时时的默认信任方向三条学术研究）第一条"真实部署的生产系统"级证据——此前三条均为事后分析或受控小实验，本条是跑在影子模式下、有真实工单驱动的端到端系统，且首次给出"修复文档→自身回答质量提升"的量化闭环数据。
- 原文：[Mind the Gap: A Deployed Multi-Agent System for Documentation Maintenance](https://arxiv.org/abs/2611.23142)

## 今日主线

今天 5 条共同指向同一个问题：我们用来判断"AI 系统是否在变好"的各类代理指标，正在被逐一拆穿与量化。基准分数不等于开发者实际合并的代码量（#1），测试通过不等于该停手的时机判断正确（#2），企业的安全姿态承诺不等于其实际政策行为（#3 的 MisAnthropic Statement 恰与 #1/#2 揭示的"分数≠真实"构成同构逻辑，只是把批判对象从模型能力扩展到公司治理），闭环仿真分数不等于真实交互行为（#4），而文档维护这件最朴素的"代理"工作，反而在真实部署中给出了目前质量最扎实的量化闭环证据（#5）。与此同时，Anthropic 今天完成了史上最大 IPO 定价——资本市场对"分数/叙事"的信任仍在以千亿美元计加码，与同日研究/联署声明对这套信任基础的拆解形成鲜明对照。

   **命中**：门槛 c（给已有页追加证据行）。
   **证据链**：2026-11-18 Higher-Scoring Coding Models Did Not Get More Work Done（arXiv 2611.23216，双重差分自然实验）。

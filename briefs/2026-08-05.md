### 1. PAST-Bench 追问：Agent 记住经验后，真的会在下一次做得更好吗？
- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv、PAST-Bench 官方仓库 / 2026-08-04
- 摘要：PAST-Bench 用 26 个场景、204 个连续任务回合，对比开启与关闭经验保留时 Agent 的后续表现，并检查改进是否真正经过“保存—检索—更新”链路。对 7 个基础模型和 4 个 Agent 框架的测试显示，跨会话改进确实存在，但不同能力和框架间差异明显；同样的总分提升，也可能缺少可归因的学习证据。
- 为何重要：这把“长期记忆有用”从产品叙事变成可控实验问题，并提醒团队不能只看任务成功率，还要验证经验是否被正确保存、调用和替换。它与持久化个人 Agent、组织记忆和可自我改进系统的评测直接相关。
- 原文：[PAST-Bench 论文](https://arxiv.org/abs/2608.04003)
- 配图：![PAST-Bench 跨会话评测框架](https://raw.githubusercontent.com/Gen-Verse/PAST-Bench/main/assets/past_bench_overview.png)
  图片来源：[PAST-Bench 官方仓库](https://github.com/Gen-Verse/PAST-Bench)

### 2. “自演化 Coding Agent”新综述划定六类可进化对象
- 领域：软件工程
- 来源 / 发布日期：arXiv、Awesome Self-Evolving Coding Agents 官方资料库 / 2026-08-04
- 摘要：这篇综述把自演化 Coding Agent 与普通 Coding Agent、通用自演化 Agent 区分开，并按 Agent 框架、记忆、技能、工具、模型和协作结构等对象整理现有研究。作者认为，可执行反馈、仓库级上下文和完整编码轨迹让软件工程天然适合自演化，同时也会放大反馈失真、基准过拟合、安全、可维护性、成本和泛化问题。
- 为何重要：Coding Agent 的竞争焦点正从“单次能修多少 issue”转向“能否把历史执行证据变成稳定、可审计的能力增量”。这套分类可直接用于设计 Agent 记忆、Skill 演化和 Harness 更新的责任边界。
- 原文：[Self-Evolving Coding Agents](https://arxiv.org/abs/2608.03392)
- 配图：![自演化 Coding Agent 分类框架](https://arxiv.org/html/2608.03392v1/x1.png)
  图片来源：[Self-Evolving Coding Agents 论文](https://arxiv.org/abs/2608.03392)

### 3. Bending Spoons 以 12.9 亿美元收购 Airtable，SaaS 高估值继续回归现金流
- 领域：创业 / 商业
- 来源 / 发布日期：Axios / 2026-08-04
- 摘要：刚在 7 月上市的 Bending Spoons 同意以约 12.9 亿美元现金收购 Airtable；Axios 估算 Airtable 自成立以来累计融资约 13.5 亿美元，而其 2021 年融资时估值曾达到约 110 亿美元。交易把一家明星协作软件公司的退出价格压回接近累计融资额，也延续了 Bending Spoons 收购成熟数字产品、集中运营和提高利润率的模式。
- 为何重要：这不是单一公司的估值回撤，而是对传统 SaaS 增长溢价、席位收费和“AI 会重写工作流”预期的一次市场定价。对创业者和投资人而言，续费质量、现金流与可被整合的运营效率正在重新压过历史融资估值。
- 原文：[Bending Spoons agrees to buy Airtable](https://www.axios.com/2026/08/04/bending-spoons-airtable)

### 4. MoRAL 把自动驾驶空间推理压进 8 GB GPU，但仍需更强真实道路验证
- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：arXiv（过去 72 小时） / 2026-08-03
- 摘要：MoRAL 用带物理含义的鸟瞰图编码 LiDAR 距离、目标类别和雷达速度，再分两阶段微调 Cosmos-Reason2-2B；在 2,304 个 nuScenes 留出帧上，它以四分之一参数规模在 8 类问题中的 7 类超过零样本 8B 基线。论文报告紧急制动召回率从 10.8% 提升至 47.8%，输出退化率从 94.1% 降至 20.8%，并可在消费级 8 GB GPU 上以 42 token/s 运行。
- 为何重要：它展示了一条不同于堆大模型的车端路线：先把传感器几何显式编码，再让小型 VLM 做推理，可能降低边缘部署成本。不过结果仍主要来自数据集与模型裁判，距离安全关键系统所需的闭环道路验证还有明显差距。
- 原文：[MoRAL 论文](https://arxiv.org/abs/2608.02449)
- 配图：![MoRAL 两阶段车端推理流程](https://arxiv.org/html/2608.02449v1/x1.png)
  图片来源：[MoRAL 论文](https://arxiv.org/abs/2608.02449)

### 5. Oilbird 用验证模型已有隐藏状态提速工具调用，训练外推理解码转向“语义寻址”
- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv / 2026-08-04
- 摘要：Oilbird 发现，训练外推式解码在工具调用流量上的主要损失不是候选续写不存在，而是精确后缀匹配找不到它；因此改用验证模型已计算的隐藏状态为候选池建立语义索引。接入 3 种既有 Draft 方法后，接受长度在相同池大小和预算下提升 24%–29%；在 API-Bank 上达到 4.4 倍自回归解码速度，高于其测试中的最强训练外基线 3.9 倍和 EAGLE-3 的 2.0 倍。
- 为何重要：Agent 工作负载包含大量结构重复、参数变化的 API 调用，正是传统精确匹配最容易漏掉的模式。若结果能在更多模型与生产流量上复现，这类无需额外训练的语义 Draft 可能成为降低 Agent 延迟和推理成本的实用基础设施。
- 原文：[Oilbird 论文](https://arxiv.org/abs/2608.03839)
- 配图：![Oilbird 语义 Draft 解码流程](https://arxiv.org/html/2608.03839v1/x1.png)
  图片来源：[Oilbird 论文](https://arxiv.org/abs/2608.03839)

## 今日主线

Agent 技术正在从单次任务成功率转向跨会话学习、能力演化和针对工具流量优化的系统工程，评测也开始要求“改进可归因”而不只是分数上涨。与此同时，资本市场在下调传统 SaaS 的历史增长溢价，自动驾驶研究则尝试用显式物理结构和小模型把推理真正压到车端。共同趋势是：行业开始用可验证效果、单位成本和部署约束取代抽象的“更智能”叙事。

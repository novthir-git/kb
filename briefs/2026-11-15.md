### 1. Termination Lag：Coding Agent 往往早就做对了，却迟迟不收手
- 领域：AI / 智能体
- 来源 / 发布日期：arXiv / 2026-11-13（v1 于 2026-11-11 UTC 上传）
- 摘要：作者在 5 个模型、2 个 agent 框架、3 个 SWE-bench 系列数据集（含 SWE-bench Verified 与 Multilingual）上，记录并重新测试 agent 每一次生成的仓库补丁，定义"终止延迟"（termination lag）——从 agent 第一次产生正确补丁到整个 run 结束之间的步数。在 38%-82% 的成功 run 中，agent 第一次修改源码就已经给出了正确解；但成功 run 里，"解完之后"的步骤占全程步数的中位数：Qwen3-Coder 为 35%-37%，Laguna-XS.2 为 54%-60%，这些多余步骤主要花在验证与探索仓库上。在 1%-8% 的 case 中，agent 后续动作反而撤销了已经正确的补丁，导致最终提交变成错误答案。
- 为何重要：这揭示了一个与"能否解出任务"正交的失效维度——agent 不仅要会解题，还要会判断"已经解完、该停了"；继续动作本身就能把对的答案改错，是一种纯粹由终止判断失误引入的、原本可避免的失败来源。证据边界：论文未披露作者机构归属；仅覆盖 5 个模型、2 个 agent 框架与 SWE-bench 系列数据集，能否外推到非代码任务未知；"1%-8% 撤销正确补丁"区间较宽，具体分布按模型/框架未在摘要页给出；暂无第三方复现。
- 原文：[Termination Lag: Coding Agents Solve Early but Stop Late](https://arxiv.org/abs/2611.14960)（检索于 2026-11-15）

### 2. SatisFix：Coding Agent 不是不会满足需求，而是会"心安理得地"选择不满足它的那个方案
- 领域：软件工程
- 来源 / 发布日期：arXiv（cs.SE）/ 2026-11-13（v1 于 2026-11-12 UTC 上传）
- 摘要：作者把"agent 在多个都能满足某项要求的实现方案里，基于自己认为合理的理由，最终选定了其实不满足该要求的那个"定义为"specification satisficing"（规格满足式妥协）。这类选择难以被发现和纠正，因为 agent 是基于自己能接受的理由做出的决定，现有自我修正方法反而会强化而非纠正它。作者提出 SatisFix：先让 agent 汇报这些选择及理由，再逐条对照任务描述核验。在 DeepSWE 与 SWE-bench Pro 上（5 种 LLM backbone、2 种 agent 框架，对照 3 条自我修正基线），SatisFix 使 pass@1 在 DeepSWE 上平均提升 5.09%，在 SWE-bench Pro 难例子集上提升 7.06%，在 DeepSWE 上比最佳基线高出 3.98%；消融显示"汇报"与"核验"两个步骤都有贡献。
- 为何重要：这是"测试通过≠满足规格"这一判断在机制层面的进一步细化——问题不是 agent 没能力满足要求，而是它在多个"自己觉得站得住脚"的选择里主动走向了不满足要求的那一个，而这正是"让模型自我检查"这套范式的盲区（自我修正会强化错误选择而非纠正）。证据边界：论文未披露作者机构归属；提升幅度基于作者选定的两个基准与两种 agent 框架组合，能否推广到更广泛代码库未知；"汇报的理由是否真实反映决策过程"本身依赖 agent 自陈，未经独立验证。
- 原文：[Eliciting and Mitigating Specification Satisficing in Coding Agents](https://arxiv.org/abs/2611.16289)（检索于 2026-11-15）

### 4. 规划器靠"想象未来"做决策，但它自带的不确定性度量测不出想象力正在衰减
- 领域：汽车 / 自动驾驶
- 来源 / 发布日期：arXiv / 2026-11-13（v1 于 2026-11-11 UTC 上传）
- 摘要：作者在 CARLA 仿真环境中，用一个 Recurrent State Space Model 世界模型配合主动推理（active inference）规划器做单种子（single-seed）案例研究，测量"模型想象出的未来状态（prior）到底保留了多少任务相关信号"——这一问题此前几乎没被直接测量过。用同一个障碍物探针分别测"观测过滤后的后验状态（posterior）"与"模型自己想象出的未来先验状态（prior）"：posterior 上探针 AUC 为 0.85，但 prior 上随想象步数增加单调衰减，15 步内从 0.85 降到 0.71，logit 分离度下降 57%。因为探针完全相同、只是输入状态不同，作者将这一损失归因于转移模型本身，而非表征能力不足。规划器自带的"集成分歧"（ensemble disagreement）式认知不确定性度量，对这种损失完全不敏感——作为障碍物分类器其 AUC 只有 0.52，等同随机。附带结果：用任务条件化加权的"预期自由能"分量可在 CARLA 中实现车道保持（路线完成率 81.2% ± 1.8%）与避障（有特权运行时坐标时 28/28 次成功避开障碍物，无特权坐标时避障成功率为 0%）。
- 为何重要：这给"规划器靠想象未来状态做决策"这条路线提出一个具体、可测量的隐患——规划器用来"知道自己不知道"的认知不确定性度量，对这类信息损失是盲的，等于一个"未知的未知"；而且损失的根源是转移模型本身，不是表征能力不足，意味着单纯加大模型规模未必能解决。证据边界：作者明确说明这是单一种子的案例研究，统计显著性与跨种子稳健性未验证；全部避障能力依赖"特权运行时坐标"，无特权坐标时避障成功率为 0%，实际可部署性存疑；机构未披露；仅 CARLA 单一仿真环境，无真实道路数据；暂无第三方复现。
- 原文：[The Posterior-Prior Epistemic Gap: When World Model Imagination Fails to Carry Task-Relevant Signals](https://arxiv.org/abs/2611.14955)（检索于 2026-11-15）

## 今日主线

前三条里有两条（Termination Lag、SatisFix）和第四条共同指向同一个母题的三个不同切面：agent／规划器"自己觉得对"的东西经常靠不住——不知道该不该停手（Termination Lag）、会心安理得地选中不满足规格的方案（SatisFix）、自带的不确定性度量测不出想象力本身在衰减（Posterior-Prior Epistemic Gap）。创业/商业的两条则是资本侧的对照：Jensen Huang 事件第一次让"AI 创投资本流动高度依赖单一个人判断"这一结构性特征遭遇现实压力测试，而 LangChain 的独立融资说明功能层 agent 工具的整合路径至少还有一条不被模型厂商收编的出路——这两条合在一起说明，AI 价值链上"控制权到底在谁手上"目前还没有唯一答案。

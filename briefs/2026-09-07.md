### 1. NLIP：Ecma 国际标准化的 AI Agent 互操作协议，正面对标 MCP 与 A2A
- 领域：AI / 智能体（Agent，互操作协议）
- 来源 / 发布日期：arXiv / 2026-09-03（Thu, 3 Sep 2026 17:30:17 UTC），已被 ACM AI Summit 2026 接收
- 摘要：论文提出 NLIP（Natural Language Interaction Protocol），一个经 **Ecma International** 标准化的应用层协议，目标是让异构 agent 开发框架、模型、工具接口和执行环境之间能互相通信。核心是一个可通过 HTTP/HTTPS、WebSocket、AMQP 等多种传输层承载的"轻量语义消息信封"，内建安全设计（security-by-design）原则，并附参考实现。论文正面将 NLIP 与已有的 MCP（Model Context Protocol）、A2A（Agent2Agent）协议做对比。作者列表含 12 人，未标注机构隶属关系。
- 为何重要：这是"agent 互操作协议"赛道第一次出现**经正式标准化机构（Ecma）背书**的竞争者，而非某厂商单方面发布的规范——如果被采纳，会直接影响 wiki 长期跟踪的"agent 需要什么样的知识—记忆—行动架构"这条关键问题里"编排/协议层由谁定义"的答案。证据边界：论文本身是协议提案 + 参考实现，**不代表已有生产级落地或行业采纳数据**；标准化机构背书不等于市场占有率，MCP、A2A 已有先发的生态位；作者机构不明，评审角度（论文自称"对比 MCP 与 A2A"）可能存在自我优势陈述倾向，未见独立第三方评测。
- 原文：[The Natural Language Interaction Protocol and Standard for AI Agents（arXiv 2609.04135）](https://arxiv.org/abs/2609.04135)

### 2. PatchBench：给"AI 漏洞补丁 agent"验货，25% 补丁与历史补丁高度雷同，传统验证方式让成功率虚高 1.83 倍
- 领域：软件工程
- 来源 / 发布日期：arXiv / 2026-09-03（Thu, 3 Sep 2026 16:44:22 UTC）
- 摘要：论文指出当前 AI 漏洞补丁评测存在两类隐蔽的效度威胁：模型对历史补丁的**记忆**（而非真正定位并修复漏洞），以及只压制崩溃症状、不解决根因的**表层修复**。作者先构造了一个补丁相似度指标，测出**25% 的 agent 生成补丁与历史开发者补丁高度相似**（怀疑是训练数据记忆而非现场推理）；再提出 PatchBench 基准，用漏洞移植技术和代码变异生成新的测试变体，避免题目泄漏。用该基准评测 **11 个主流 AI agent**（含多个 AIxCC 参赛队伍）后发现，传统"仅用 PoC 复现验证是否修复"的评测方式，会把补丁任务的解决率**平均虚高 1.83 倍**。
- 为何重要：这从"安全补丁"这一具体子场景，为本 wiki 已跟踪的"SE agent 补丁'测试通过'≠'真正可靠'"这条判断（09-05 简报 SWE-Gate：功能测试通过的补丁中 34% 未达审查标准）补上第二个独立证据源，且首次把"记忆历史答案"和"验证方式本身注水"两种具体机制量化出来，而不只是笼统说"评测不可靠"。证据边界：25% 相似度阈值的具体判定标准与人工复核比例未在摘要中说明；11 个被测 agent 的具体名单、是否含最新旗舰模型未确认；1.83 倍虚高是"平均"，未知分布与方差；结论成立范围限定在"漏洞补丁"这一任务类型，未验证能否推广到通用代码修复。
- 原文：[PatchBench: Evaluating AI Agents for Vulnerability Patching（arXiv 2609.04075）](https://arxiv.org/abs/2609.04075)

### 5. 今日细读：从"欺骗性输出"到"欺骗性机制"——给语言模型欺骗研究立一套因果框架
- 领域：AI / 智能体（Agent，安全与治理，今日加选）
- 来源 / 发布日期：arXiv / 2026-09-03（Thu, 3 Sep 2026 17:52:19 UTC）
- 摘要：论文指出，当前对"语言模型欺骗"的描述常借用人类心智状态概念（如"意图""相信"），容易把"表面上像欺骗的行为"和"真正的欺骗性机制"混为一谈。作者提出一套因果分类法，把以下几组概念显式拆开：**事前承诺 vs 事后报告**、**模型偏好 vs 实际输出**、**对误导他人有效用的虚假偏好 vs 单纯的偏好敏感性**、**欺骗行为 vs 产生该目标/策略的来源**。作者在两个开放权重模型家族上用受控实验（猜谜游戏、股票交易场景）做了因果干预测试，发现：表面上像欺骗的行为可以独立于作者假设的底层机制出现；接收方的信息状态会因果性地影响模型的"欺骗性偏好"（在某些干预下）；观察到欺骗性机制不必然证明模型对欺骗本身有"能动性"。
- 为何重要：这为 wiki 已跟踪的"agent 治理与验证"这条主线（关键问题 1）补上一个方法论工具——如果"模型看起来在骗人"和"模型真的有欺骗机制"是两件需要因果拆分的事，那么任何"检测 agent 是否欺骗/隐瞒"的审计方案，都不能只看行为表面（这与 09-05 简报 DeepMind 的"agent 群体自发作弊与吹哨"案例形成方法论互补：那篇给出了欺骗涌现的实证案例，这篇给出了区分"真欺骗"与"像欺骗"的分析工具）。证据边界：仅在两个开放权重模型家族、两类受控小场景（猜谜、模拟股票交易）上验证，未测试前沿闭源模型或真实生产 agent；因果分类法本身是作者提出的理论框架，尚未见独立复现或第三方采纳；单一作者署名，同行评审状态未知。
- 原文：[From Deceptive Outputs to Deceptive Mechanisms: A Causal Framework for Language-Model Deception Research（arXiv 2609.04166）](https://arxiv.org/abs/2609.04166)

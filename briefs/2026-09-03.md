### 1. 受控实验证实：LLM Agent 的长时任务成功率服从"几何衰减律"，模型再大也无法避免最终崩溃
- 领域：AI / 智能体（Agent）
- 来源 / 发布日期：arXiv / 2026-08-31 前后（v1，据检索结果"3 天前"的相对时间推算，未核实精确 UTC 时间戳）
- 摘要：论文覆盖 9 个模型（6 个 1.2B–671B 参数的开源模型 + 3 个已部署的商用系统）、4 类任务族（含一类真正的 agentic 工具调用循环）、5 种任务时长、3 种上下文设置的受控实验。作者发现任务成功率服从一个由单一"每步可靠性参数"决定的几何衰减规律：该参数随模型规模上升，但即使最强模型也会饱和在远低于 1 的水平——这意味着只要任务链条足够长，崩溃在数学上是必然的,不是工程疏忽的偶发结果。

### 2. "别让模型直接写 YAML"：结构化字段意图 + 确定性重写，把 GitOps 自动修复的静默错误率从两位数降到零
- 领域：软件工程
- 来源 / 发布日期：arXiv / 2026-09-01 前后（据同批 cs.SE 论文检索结果推算）
- 摘要：作者在真实 Kubernetes manifest 上评测"让 LLM agent 直接生成修复补丁"的做法，发现没有一种文本生成策略适合无人值守的自动化：走严格 patch 校验时统一 diff 几乎全部无法应用；换成宽容的 GNU patch 虽然 96% 能应用，却会静默误改约 1/7（14%–20%）；整文件重写则依赖模型能力——小模型会损坏文件，前沿模型通常正确但结果不确定。作者的方案是让 agent 只输出结构化的"字段变更意图"，再由确定性流水线按 (kind, name) 索引 manifest,用 YAML 解析器的节点位置标记定位目标标量的精确字符区间并只替换该区间;文件从不被重新序列化,因此 diff 天然最小、格式和注释保留,且编辑结果与模型无关、完全确定。
- 为何重要：这是一条对"人工审查/信任模型生成的运维改动"这一常见默认操作方式的直接反证——即便用宽容工具、即便看起来"能应用"，也可能有一到两成静默改错。它给"agent 的知识与执行必须区分权威表示与派生生成"这个 wiki 关键问题提供了一个具体、可复现的工程解法样本。证据边界：论文出自单一作者、8 页篇幅，只在 Kubernetes manifest 场景验证，未核实是否覆盖 Terraform、Helm values 等其他常见 IaC 格式,也没有生产环境的长期采用数据；结论来自检索摘要,未读全文方法论细节。
- 原文：[Don't Let the Model Write the YAML（arXiv 2609.00227）](https://arxiv.org/abs/2609.00227)

### 5. Delegation Without Trust：主流 Agent 框架在"假设模型已被劫持"的前提下全部无法自证安全（今日细读）
- 领域：AI / 智能体（Agent，今日加选）
- 来源 / 发布日期：arXiv / 2026-08-31
- 摘要：论文主张多智能体授权应在"模型可能已被攻击者劫持"的假设下评估——一个正确的系统应满足:即便 agent 已被完全 prompt injection 控制,也不能超出被显式委托的权限范围。作者据此定义四类具体攻击者（confused deputy、令牌窃取与重放、prompt injection 权限提升、子 agent 被攻陷）,并推导出治理系统必须满足的八条安全要求。差距分析显示：默认的 agent 运行时在全部四类威胁前都会失守;在检索到的四个主流框架中,三个没有内建的权限隔离机制,一个只有部分隔离;现有的任何单一标准都无法独立覆盖全部要求——跨 agent 委托所需的安全原语目前尚未被组合到位。
- 为何重要：这篇与 2026-08-31 简报收录的 SARA（把"工具输出诱导动作"与"执行授权"拆开）形成呼应,把同一问题从单点机制方案升级为系统性威胁分类和框架级差距盘点,直接对应 wiki 关键问题"知识与规格如何在人和 agent 之间不越权、不漂移"。证据边界：被评测的"四个主流框架"具体名称未在检索摘要中确认,差距分析结果为作者自评,尚无独立复现;仅检索模式下未读原文的评测方法与八条要求的完整定义。

## 今日主线

今天五条共同指向同一个转折点：**agent 能力越强，越需要用"结构性约束"而不是"更好的生成"来换取生产可靠**。Agent Rot 论文把"长时任务必然衰减"钉成了跨模型的数学规律,GitOps 论文把"信任模型直接写配置"换成了确定性的最小改动机制,Delegation Without Trust 把授权问题从单点方案升级为框架级差距盘点——三者都在把可靠性从"模型能力"搬到"运行时architecture"。物理世界一侧同样如此：Lyte 的资本押注押的是"芯片到软件"的全栈可验证感知,而 Waymo 与 Zoox 在同一周展示了"全无人商业化"与"配安全员测试"两种不同的验证成熟度。这与本 wiki 长期跟踪的核心判断一致：agent 的瓶颈已从能力转向治理与验证。

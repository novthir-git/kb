## 核心要点
- [[Loop Engineering]] 的重点不是让 agent 多跑几轮，而是设计**能吸收反馈并继续推进的闭环**。
- Andrew Ng 将 0-to-1 产品开发拆成三层速度不同的循环：agentic coding loop（分钟级）、developer feedback loop（小时级）、external feedback loop（天/周级）。
- [[Codex]] / Claude Code 这类 coding agent 的能力提升，使开发者从手工 QA 逐步上移到产品判断：功能取舍、UI、用户流、规格澄清。
- [[Evals]] 是把"愿景"压成 agent 可执行规格的关键接口：当 agent 反复踩同类问题时，应把问题固化成 evals，而不是只靠下一次口头提醒。
- Andrew Ng 反对把人的贡献只称为"taste"：更可操作的表述是**人类有 context advantage**，因为人知道用户和产品场景里 AI 不知道的信息。
- 外部反馈循环仍然慢：朋友反馈、alpha 测试、线上 A/B 测试会反过来更新开发者愿景，再推动规格和 agent coding loop。

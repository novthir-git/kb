# Codex Agent 采用曲线（2026）

## 核心结论
[[Codex]] 的增长不是"程序员工具用得更多"，而是**从编码工具变成通用 agent 工作平台**，
且**增长最快的是非开发者**——这标志"agent 化工作"正在跨越技术人群边界。
数据来自 OpenAI × 哥伦比亚 × 杜克 × 宾大的联合报告
（[[2026-06-25-Axios-Codex-agent-用量增长-源摘要]]；学术版《The Shift to Agentic AI: Evidence from Codex》）。

## 关键量化
| 维度 | 数字 |
|---|---|
| 周活用户增速 | 2026-01-01 → 06-01 增长 **5 倍以上** |
| Codex 在输出 token 中占比 | OpenAI 员工 **99.8%** · 组织 **63%** · 个人 **16.5%** |
| 组织内 Codex 渗透率 | 2025-08 ≈0% → 现约 **17%** |
| 非开发者用户增长（自 2025-08） | 个人 **137×** · 组织 **189×** · OpenAI 内部 **12×**（仅见于 Axios 重建稿，论文正文未见，待核） |
| Agent 使用强度（**OpenAI 员工** 99 分位） | 单日约 **71 小时** agent turns，同一时刻有多个 agent 并行；外部组织 / 个人用户的日运行时长"substantially lower" |

> ⚠️ 矛盾：[[2026-06-25-Axios-Codex-agent-用量增长-源摘要|Axios 重建稿]] 称"99 分位用户单日 60+ 小时"，但底层论文 v1 写的是
> OpenAI 员工 99 分位约 71 小时/日，并说外部用户"remains substantially lower"（99 分位只分别增长约 25% / 50%）。
> 数值不冲突（71 也是 60+），出入在人群口径。137× / 189× / 12× 在论文正文与图注中都检索不到，
> Fig. 2 只给以 2025-08-01 为 1 的指数曲线，倍数可能来自读图或转述，待核。（发现于 2026-11-07）

## 三点解读
1. **采用梯度**：OpenAI 内部（99.8%）远超企业（63%）远超个人（16.5%）——
   > 综合：内部渗透率是外部的先行指标，企业侧仍有巨大爬坡空间。
2. **非开发者是主引擎**：论文确认"growth is faster among Non-developers"（具体倍数待核，见上），说明价值主张正从"写代码"变为"完成工作"；
   但论文也说个人与组织用户仍集中在开发者人群，非开发者的外溢目前在 OpenAI 内部最明显。
   与 [[Claude Cowork]] 主打"非技术知识工作者"的判断同频（见 [[cowork-saas-资本市场冲击]]）。
3. **并行 agent 放大产出**："约 71 小时/天"只有在**一人调度多 agent**时才可能。这是 OpenAI 员工前 1% 的前沿用法，
   外部用户的中位数仍只是间歇使用；综合：它是先行指标，不是一般用户的现状——
   范式从"人写"转向"人调度"，能力基础见 [[building-effective-agents]] 的 orchestrator-workers / 并行化。

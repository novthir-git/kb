# 叙事与故事结构方法论

## 核心判断

综合：常见“故事方法大全”把三种不同层级的东西混在了一起：

1. **描述性理论**：解释叙事由什么构成、如何产生效果，如 narratology、Chatman、Genette。
2. **生成与诊断方法**：帮助创作者构造或检查情节，如 Story Spine、Hero's Journey、Story Grid。
3. **表达模板**：把既有材料压缩成特定交付物，如 ABT、SCQA、STAR、What? So What? Now What?。

综合：因此，单纯罗列框架只能回答“有什么工具”，不能回答“叙事系统如何运作”。
Chatman 将叙事区分为讲述的内容 **Story（what）** 与呈现方式
**Discourse（way）**，并在两层下继续分析事件、因果、人物、时间、视角与声音
（https://utpdistribution.com/9780801491863/story-and-discourse/ ，检索于 2026-07-27）。
修辞叙事理论则进一步关心作者、文本与读者之间的递归关系
（https://ohiostatepress.org/books/BookPages/PhelanNarrative.htm ，检索于 2026-07-27）。

> 综合：可将完整叙事压缩为：
> **Narrative = Situation（谁为何而讲）× Story（讲什么）× Discourse（怎么讲）
> → Audience Effect（听众发生什么变化）**。
> 对事实性内容，还必须外加 **Evidence / Truth Contract（凭什么相信）**。

综合：这不是数学公式，而是防漏项的系统模型：同一组事件可以有不同讲法；同一种讲法面对不同听众，
也会产生不同意义。故事连贯只证明表达闭合，不证明事实或结论为真。

## 七层叙事系统

> 综合：以下七层以 narratology 的 Story–Discourse 区分为骨架，再加入修辞情境、
> 认知效果和事实性内容的证据约束；它是一套跨文学、案例、演讲和商业沟通的分析框架，
> 不是任何单一学派的原始模型。

| 层级 | 核心问题 | 主要内容 | 典型理论或工具 |
|---|---|---|---|
| 1. 叙事情境 Situation | 谁在什么场合讲给谁？希望改变什么？ | 讲述者、听众、目的、媒介、关系与时机 | 修辞叙事理论、audience design |
| 2. 故事世界 Storyworld | 世界里存在什么、发生了什么？ | 人物、目标、事件、时间、空间、规则与初始状态 | Chatman 的 Story、cognitive narratology |
| 3. 因果与变化 Plot | 为什么下一件事会发生？ | 扰动、欲望、阻碍、选择、后果、转折与新状态 | Aristotle、Story Spine、Story Grid、Hero's Journey |
| 4. 叙事话语 Discourse | 这些材料按什么方式呈现？ | 取舍、顺序、时长、频率、视角、声音、距离与信息控制 | Genette、Chatman |
| 5. 意义与体验 Effect | 为什么值得听？听众经历什么变化？ | stakes、主题、价值变化、期待、情绪、认知与行动 | rhetorical / cognitive narratology、Sparkline |
| 6. 真实性与论证 Evidence | 事实和结论是否成立？ | 来源、证据、推理桥梁、限定条件、反例与不确定性 | Toulmin Model；事实叙事必需 |
| 7. 交付结构 Delivery | 最终要压缩成什么形式？ | 开场、摘要、汇报、案例、复盘、提案或长篇作品 | ABT、SCQA/Pyramid、STAR、W3 |

综合：七层之间不是七段文字，而是七个设计问题。小说的第 6 层主要检查世界内部的一致性与
虚构契约；研究、投资和管理沟通则必须检查外部证据。简短决策材料可能几乎不需要第 2–5 层的
戏剧化展开，但不能省略第 1、6、7 层。**并非所有好沟通都应该被故事化。**

## 工具层：五类沟通任务

> 综合：下面是第 7 层的任务路由，不是五套平行的叙事理论。

| 类型 | 回答的问题 | 代表方法 |
|---|---|---|
| 故事结构 | 一个主体如何因冲突、选择和后果而改变？ | 叙事弧、Story Spine、Hero's Journey |
| 说服结构 | 为什么听众应接受这个判断或采取行动？ | ABT、SCQ → Answer + Pyramid、Duarte Sparkline |
| 案例结构 | 在具体情境中，我做了什么并带来什么结果？ | STAR(R)、CAR |
| 复盘结构 | 事实意味着什么，下一步怎么办？ | What? So What? Now What? |
| 论证结构 | 证据如何支持主张，在哪些条件下不成立？ | Toulmin Model |

综合：先判断**沟通任务**，再选交付模板；模板服务于任务，不能反过来支配材料。

## 第 3 层展开：故事的原型因果引擎

Aristotle 对完整情节的基础要求是有开端、中段和结尾，但这只解决“完整性”，
还没有自动产生张力或因果（https://classics.mit.edu/Aristotle/poetics.1.1.html ，
检索于 2026-07-27）。

> 综合：对大多数实践型故事，可用下面的原型推进器检查第 3 层：
> **初始状态 → 主体目标 → 扰动或阻碍 → 选择与行动 → 因果后果 → 新状态 → 意义**。

这是一种高可用原型，不是叙事的必要充分条件。David Herman 将事件排序、故事世界的建构或扰动、
以及主体“经历起来是什么样”等视为程度性的基本属性，而不是判定所有叙事的刚性清单
（https://onlinelibrary.wiley.com/doi/book/10.1002/9781444305920 ，检索于 2026-07-27）。

Kenn Adams 的 Story Spine 进一步把故事拆成常态、扰动、连续后果、高潮与新常态：

```text
从前……
每天……
但有一天……
因此……
因此……
直到最终……
从此以后……
```

其中“因此”比“然后”重要：前者要求上一事件导致下一事件，后者只记录先后。
Kenn Adams 的自述将其创建时间追溯至 1991 年；Khan Academy 的 Pixar in a Box 课程
将 Story Spine 作为故事结构工具讲授，因此更准确的说法是“被 Pixar 教学体系使用”，
而不是“由 Pixar 发明”
（https://www.aerogrammestudio.com/2013/06/05/back-to-the-story-spine/ ；
https://www.khanacademy.org/partner-content/hass-storytelling/storytelling-pixar-in-a-box/ah-piab-story-structure/v/video1a-fine ，
均检索于 2026-07-27）。

## 工具映射：每种方法只覆盖局部

> 综合：以下映射用于说明方法在七层系统中的位置；没有一种模板能独立覆盖全部七层。

| 方法 | 所在层 | 核心骨架 | 最适合 | 常见误用 |
|---|---|---|---|---|
| 叙事弧 | 3、5 | 背景 → 触发事件 → 张力上升 → 关键选择 → 结果 → 新状态 | 长案例、纪录片、数据故事 | 只沿时间线汇报分析过程 |
| Story Spine | 3 | 常态 → 扰动 → 连锁后果 → 最终解决 → 新常态 | 快速构思、品牌起源、短案例 | 填满句式却没有真实选择和代价 |
| Hero's Journey | 3、5 | 离开 → 试炼与转化 → 带着成果归来 | 身份转变、人物成长、长篇故事 | 把描述性母题当成必填步骤 |
| Story Grid | 3、5 | 触发 → 递进复杂化/转折 → 危机选择 → 高潮 → 解决 | 小说、场景诊断、长篇编辑 | 把一个创作学派误作学界共识 |
| ABT | 7，借用 3 | And 背景 → But 矛盾 → Therefore 回应 | 30 秒观点、摘要、开场 | 用三句话代替机制和证据 |
| SCQ → Answer + Pyramid | 7，连接 6 | 情境 → 复杂化 → 问题 → 答案；答案下分层给理由与证据 | 管理汇报、提案、决策材料 | 延迟答案；理由重叠或遗漏 |
| Duarte Sparkline | 5、7 | “现实”与“可能未来”反复对照 → 行动后的新状态 | 愿景演讲、变革沟通、销售 | 未来宏大，却没有可信路径 |
| STAR(R) / CAR | 7 | 情境/挑战 → 任务 → 行动 → 结果 → 反思 | 面试、个人贡献、项目案例 | 背景过长；结果不可验证 |
| What? So What? Now What? | 7 | 可观察事实 → 意义/模式 → 行动 | 复盘、数据解读、会议总结 | 在事实层混入判断 |
| Toulmin Model | 6 | 主张 → 证据 → 推理桥梁 → 支撑 → 限定条件 → 反例/回应 | 研究、投资判断、争议分析 | 只列数据，不解释如何推出结论 |

各方法的原始定义或官方介绍分别见 Story Grid
（https://storygrid.com/ ）、ABT
（https://abtnarrative.com/ ）、Minto SCQ/Pyramid
（https://barbaraminto.com/ ）、Duarte Sparkline
（https://www.duarte.com/resources/communication-skills/business-storytelling/ ）、
STAR(R)/CAR
（https://governmentdigitalanddatahub.campaign.gov.uk/join/government-digital-and-data-careers/prepare-for-your-interview/starr-and-car-techniques/ ）、
W3（https://www.liberatingstructures.com/what-so-what-now-what ）与 Toulmin
（https://www.blinn.edu/writing-centers/wide/toulmin-argument.html ），均检索于 2026-07-27。

Hero's Journey 的原始大结构是 separation、initiation、return；17 个阶段并非每个故事都必须完整出现
（https://www.jcf.org/learn/joseph-campbell-heros-journey ，检索于 2026-07-27）。

## 按场景快速选择

> 综合：先选任务和证据要求，再选一个主模板；其他方法只作为局部检查器。

| 任务 | 首选 | 可叠加 |
|---|---|---|
| 一句话讲清复杂观点 | ABT | Toulmin 检查证据桥梁 |
| 工作汇报或争取决策 | SCQ → Answer + Pyramid | Sparkline 展示改变前后 |
| 分享个人经历 | STAR(R) | Story Spine 增强因果与转变 |
| 项目复盘 | What? So What? Now What? | STAR(R) 说明关键行动 |
| 数据分析汇报 | SCQ → Answer | 叙事弧围绕听众关心的张力组织证据 |
| 品牌、产品或客户案例 | Story Spine | ABT 压缩成一句核心信息 |
| 愿景型演讲 | Duarte Sparkline | ABT 明确核心矛盾与行动 |
| 研究或投资判断 | Toulmin | SCQ → Answer 负责呈现顺序 |
| 小说、电影、长篇人物故事 | 叙事弧 | 有明确身份转变时再用 Hero's Journey |

综合：数据叙事也不等于把图表排成时间线。应围绕听众的认知缺口组织：
背景 → 异常或冲突 → 关键证据 → 解释 → 决策；通常无需讲述分析者发现结论的全过程
（https://www.storytellingwithdata.com/blog/2020/5/21/the-structures-of-story ，
检索于 2026-07-27）。

## 一套可复用的混合骨架

综合：下面的模板组合了 ABT 的冲突、SCQ 的读者问题、Toulmin 的证据桥梁和 W3 的行动闭环，
适用于事实性提案或决策沟通；它不是小说或所有故事的通用结构：

```text
过去，我们通常认为……                  （情境 / And）
而且已有……                            （共识或事实）
但现在出现了……                        （冲突 / But）
如果不处理，代价是……                  （stakes）
真正的问题不是……，而是……              （问题重构）
因此，我们主张/选择……                  （Answer / Therefore）
证据是……，它能支持结论是因为……          （grounds + warrant）
这个结论只在……条件下成立，反例是……      （qualifier + rebuttal）
结果或预期变化是……                     （new state）
对你而言，下一步是……                   （Now What）
```

综合：这套模板不是要求每次写十段，而是一个检查表。短内容可压缩为三句 ABT；
高风险决策则应展开证据、限定条件和反例。

## 示例：Agent 生产落地

```text
团队已经能快速做出 Agent demo，模型能力也持续提升；
但是生产环境中的权限、评估、监控与故障恢复，使 demo 成功不等于规模化价值；
因此落地重点应从“选择更强模型”，转向建设 eval、反馈闭环和治理体系。
```

这个 ABT 的 “But” 由 [[agent-生产级落地的鸿沟]] 提供事实张力；
“Therefore” 的机制依据来自 [[Evals]] 与 [[Loop Engineering]]。若要写成严谨报告，
还需要补充采用率、故障率、人工介入率等证据，并声明适用范围，不能让三句叙事替代论证。

## 七个常见失败模式

> 综合：以下失败模式用于从七层反查材料、因果、受众、证据与交付结构是否错位。

1. **用时间线代替因果**：充满“然后”，没有“因此”。
2. **有冲突但没有 stakes**：问题存在，却没有说明为何与听众有关。
3. **作者充当英雄**：只讲“我做了什么”，没有呈现听众、客户或真实主体的改变。
4. **为悬念延迟结论**：管理层已经需要决策，却被迫重走分析者的发现过程。
5. **把结构当证据**：故事连贯不等于结论为真；好故事也可能只是叙事偏误。
6. **制造虚假转变**：结尾宣称“彻底改变”，证据只支持局部改善。
7. **方法堆叠**：同时套多个框架导致内容机械；每次只选一个主结构，其余只作检查。

> 综合：高风险沟通应遵循“结论优先、证据可查、推断标注、反例保留”。
> 故事结构负责让因果和意义可理解，不能授权作者省略不利证据或夸大确定性。

## 十分钟七层构建流程

> 综合：按“是否需要叙事 → 七层设计 → 最终选模板”的顺序执行，避免先套格式再找材料。

1. **先判断是否需要故事**：如果听众只需要一个可验证的答案，优先用结论—证据结构，不制造情节。
2. **Situation**：写清谁在什么场合讲给谁，以及希望其认知、感受或行动发生什么变化。
3. **Storyworld**：列出人物、事实、事件、时间和约束；只保留与目的有关的材料。
4. **Plot**：用一句话写出“初始状态 → 扰动 → 选择 → 后果 → 新状态”；只有时间先后而无变化时，不算完整因果弧。
5. **Discourse**：决定从哪里开始、哪些提前或延后、谁来看、谁来说、什么暂不揭示。
6. **Effect**：明确 stakes、主题和听众最终应理解或感受到的变化，避免把作者自己默认成英雄。
7. **Evidence**：事实性内容逐项标记事实、推断、来源、限定条件和反例；故事顺畅不能替代这一步。
8. **Delivery**：最后才选择 ABT、SCQA、STAR、W3 或长篇结构，并删除不改变因果、意义、证据或行动的细节。

## 系统性资料与阅读路径

综合：没有一篇文章能同时代表全部叙事学与全部应用场景。更可靠的路径是先掌握共同骨架，
再按用途进入不同分支：

1. **总览**：[The Cambridge Introduction to Narrative](https://www.cambridge.org/core/books/the-cambridge-introduction-to-narrative/C3DD73A6178BEB669888CCAA1D81A099)
   将叙事放在文学、电影、新闻、历史与日常生活中统一讨论。
2. **基础骨架**：[Story and Discourse](https://utpdistribution.com/9780801491863/story-and-discourse/)
   系统展开 Story / Discourse、事件、因果、时间、人物、视角和声音。
3. **开放参考手册**：[The Living Handbook of Narratology](https://www-archiv.fdm.uni-hamburg.de/lhn/contents.html)
   可按 character、plot、time、focalization、narrator、reader、factuality、ethics 等概念查阅；
   站方说明其动态修订已于 2019 年停止，因此适合作为经典概念索引，不应视为持续更新的前沿综述。
4. **不同学派的边界**：[Narrative Theory: Core Concepts and Critical Debates](https://ohiostatepress.org/books/BookPages/HermanNarrative.html)
   用同一组核心概念比较修辞、女性主义、认知和反摹仿等路径，避免把单一学派当成统一答案。
5. **实践创作与诊断**：[Story Grid](https://storygrid.com/)
   覆盖 genre、story units、场景、转折、危机、高潮与编辑诊断；它是相对完整的实务体系，
   但属于特定创作学派而非叙事学共识。

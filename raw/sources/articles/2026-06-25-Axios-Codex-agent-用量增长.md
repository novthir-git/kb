# OpenAI's Codex agents are growing in popularity（Axios, 2026-06-25）

## 核心叙事
Codex——OpenAI 的 agentic 编码 / 工作平台——用量正在加速增长，且增长最快的
群体不是开发者，而是**非开发者**。Codex 定位正从"程序员工具"外扩为"通用 agent 工作平台"。

## 关键数据（据 OpenAI/哥大/杜克/宾大联合报告）
- **周活跃用户**：2026-01-01 → 06-01 增长 **5 倍以上**。
- **输出 token 中经 Codex 产生的占比**：
  - OpenAI 员工 **99.8%**
  - 组织（企业）用户 **63%**
  - 个人用户 **16.5%**
- **组织内 Codex 渗透率**（ChatGPT+Codex 活跃用户中用到 Codex 的比例）：
  2025-08 略高于 **0%** → 现约 **17%**。
- **非开发者用户增长（自 2025-08 起）**：
  - 个人用户 **137×**
  - 组织用户 **189×**
  - OpenAI 内部 **12×**
  - （非开发岗位包括律师、招聘等）
- **Agent 使用强度**：到 2026-06，99 分位用户单日可产生 **60+ 小时**的 Codex agent turns，
  分布在**多个并行 agent** 上。

## 要点解读
- 增长主引擎是非技术人群 → "人人皆可编排 agent"的趋势。
- "60 小时/天"意味着范式从"人写代码"转向"人调度一群并行 agent"，单个用户产出被 agent 数量放大。

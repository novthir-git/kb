一次定位级的迁移

2026 年 7 月 7 日,Anthropic 把 Cowork 从桌面端搬到云。

云模式带来的

四个关键能力

后台执行是最大卖点,其余三项围绕「跨设备、少打扰」展开。

⚡后台持续执行

关掉笔记本任务照跑,可从任意设备打开同一会话取回成品。定时任务全在远端跑,不需要电脑醒着。

在会话里输入 /schedule 设置周期或定点任务。"定时任务在远端运行,不需要你的电脑开机或桌面 app 打开。"

你最关心的

怎么让它处理本地文件夹

授权连接 → 桌面 app 当桥 → Claude 按需读取。

在 Claude 桌面 app 里点 「Add folder」(添加文件夹),选中目标目录,它(及子目录)就成为本次会话的可读写上下文。之后直接说"处理 XX 文件夹里的文件"即可,不用逐个上传。前提是桌面 app 开着且在线——关掉或纯从手机/web 端,这条桥就断了。

📌读是快照

读到的是那一刻的副本;你之后改了文件不会自动同步,需要重新读。

✍️写回要确认

结果可写回你指定路径,但覆盖/删除会先问你。删除受限:只能把文件挪进 _to_delete/ 让你自己清。

隐私要点

文件夹会一次性上传到云吗?

结论

不会。连接文件夹只是「授权」,不等于上传。上传是按需、逐文件发生的——只有 Claude 为完成任务真正要读某个文件时,才把那一个文件的副本暂存到云端隔离工作区。没被点名读到的文件,不会离开你的电脑。

授权 ≠ 上传

加文件夹的那一刻,云端没有拷走任何内容,只是获得了「能看见」的权限。

列目录 ≠ 上传内容

浏览文件夹拿到的是文件名、大小、修改时间等元数据,正文没有离开你电脑。这一步很轻,可扫整个目录树。

暂存(stage)才是真上传,且挑着传

只有要读/处理的那几个文件被复制到云端。批量还有上限(单次数十个、单文件与总量都有大小限),真处理大文件夹是分批取,不是一次灌。

传上去的是快照副本

存在绑定你账户的隔离环境,会话结束回收;不是把文件夹挂载到云做实时镜像。想更保守,可只连一个更小的子文件夹。

连接层

工具与集成

Cowork 通过这些通道够到外部系统与产出交付物。

🔌MCP

Model Context Protocol——连外部系统的开放标准;Cowork 插件本质就是 MCP Server。

🌐Claude in Chrome

浏览器自动化;配合服务端的 web search / fetch(受限于搜索结果与分享的 URL)。

🧩Plugins

打包 skills 与 sub-agents,面向 legal / sales / marketing / data 等场景。

📊Live Artifacts

表格 / 演示 / 文档等实时产出物——目前仍是桌面独占。
